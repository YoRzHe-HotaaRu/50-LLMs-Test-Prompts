## 01 Living Ink

**Animated SVGs**

A living vector scene. Not a logo spin.

> **01 / 50**
>
> Create a single HTML file of an animated SVG car racing a coastal road at sunset. Headlights, a wet road, the sun dropping into the sea, the car taking real turns. Art style: 1980s Japanese city-pop poster, flat shapes, candy orange and teal, no outlines. It should feel like a short film, not a clipart car on a stripe. Go all out. Use a suitable name for the html file.

> **02 / 50**
>
> Create a single HTML file of an animated SVG hummingbird drinking from a flower. Wings beating fast, pollen in the air, the flower swaying, light through the petals. Art style: 19th century natural-history watercolor on cream paper, fine ink lines, wet color. Go all out. Use a suitable name for the html file.

> **03 / 50**
>
> Create a single HTML file of an animated SVG steam train crossing a mountain bridge at night. Sparks from the stack, lit windows, a river far below, the train actually crossing. Art style: 1930s railway travel poster, deep navy, a gold window strip, big simple shapes. Go all out. Use a suitable name for the html file.

> **04 / 50**
>
> Create a single HTML file of an animated SVG koi pond in front of a Japanese temple. Fish under the surface, ripples, lanterns, a temple reflection that breaks when a koi moves. Art style: ukiyo-e, flat color, bold water patterns, one red lantern. Go all out. Use a suitable name for the html file.

> **05 / 50**
>
> Create a single HTML file of an animated SVG F1 pit stop that lasts about two seconds. The car slams in, the crew swarm, tires change, it launches out. Art style: 1990s F1 broadcast freeze-frame, harsh floodlight, invented livery, no real team logos. Fast, tight, and easy to read. Go all out. Use a suitable name for the html file.

## 02 Glass Worlds

**Three.js**

A real 3D place you can look around.

> **06 / 50**
>
> Create a single HTML file of a walkable 3D Japanese garden in Three.js. Stone path, koi, a tea house, maple, you can look around. Art style: late-afternoon Kyoto, warm Firewatch-like light, soft photoreal, quiet. A place, not a plane with three trees. Go all out. Use a suitable name for the html file.

> **07 / 50**
>
> Create a single HTML file of a 3D Earth you can spin. Clouds, city lights on the night side, a thin atmosphere. Art style: NASA Blue Marble documentary, not a cartoon globe. It should feel like a real sphere sitting in the dark. Go all out. Use a suitable name for the html file.

> **08 / 50**
>
> Create a single HTML file of a giant 3D aquarium you can look around. Schools of fish, plants, light through the water, something big in the back. Art style: BBC Blue Planet, god rays, slow, photoreal water. Go all out. Use a suitable name for the html file.

> **09 / 50**
>
> Create a single HTML file of a cozy 3D cabin in the snow you can walk through. A fire going, windows onto the storm, wood, a mug. Art style: cozy-game interior, amber lamps, snow outside a cold blue, Ghibli-warm inside. Go all out. Use a suitable name for the html file.

> **10 / 50**
>
> Create a single HTML file of a 3D Venice canal at night you can ride through. Lanterns on the water, buildings, a gondola path. Art style: wet amber night, photoreal water, like a photo from a vaporetto. Reflections are the whole point. Go all out. Use a suitable name for the html file.
