## 01 Living Ink

**Animated SVGs**

A living vector scene. Not a logo spin.

> **01 / 50**
>
> Create a single HTML file of an animated SVG mountain lake at dawn. Mist lifting, layered hills, pines, a still lake with a slow reflection, clouds drifting, a few birds as small marks. Scenery only, no people, no buildings. Art style: Ghibli background painting, soft greens and gold, big quiet shapes. It should feel like a place you could sit in, not clipart hills. Go all out. Use a suitable name for the html file.

> **02 / 50**
>
> Create a single HTML file of an animated SVG hummingbird drinking from a flower. It hovers, then drinks, wings beating fast, pollen and dew in the air, the flower swaying, a paper-shadow under the bird. Art style: 19th century natural-history watercolor on cream paper, fine ink lines, wet color, a small invented latin label in the corner. Go all out. Use a suitable name for the html file.

> **03 / 50**
>
> Create a single HTML file of an animated SVG steam train crossing a mountain viaduct at night. Sparks from the stack, gold-lit windows, smoke, a river and a village of tiny lights far below, the train actually crossing and looping. Art style: 1930s railway travel poster, deep navy, a gold window strip, a pale moon, big simple shapes. Go all out. Use a suitable name for the html file.

> **04 / 50**
>
> Create a single HTML file of an animated SVG peacock opening its train in a garden. The fan fills the page, eyespots catching light, a slow turn, a few other birds as small marks, plants around the feet. Art style: Mughal miniature, gold ground, jewel greens and blues, fine pattern, a thin ornamental border. Make the bird the whole show, not a sticker with a triangle tail. Go all out. Use a suitable name for the html file.

> **05 / 50**
>
> Create a single HTML file of an animated SVG music box that opens. The lid lifts, a ballerina turns, tiny gears show under glass, a few notes as gold specks, then it closes and starts again. Art style: enamel and brass, cream, gold, a bit of dusty rose, like a Fabergé toy on a dark cloth. The mechanism is the show. Go all out. Use a suitable name for the html file.

## 02 Glass Worlds

**Three.js**

A big 3D simulation. Spectacle, not a quiet room.

> **06 / 50**
>
> Create a single HTML file of a 3D simulation of all-out war between two invented medieval kingdoms. A brutal battle in a valley: cavalry charges that hit, melee, arrow storms, siege engines slamming walls, fire, mud, banners in the smoke. The fight has to actually move and hurt, not idle in place. Switch camera views (ridge, in the melee, aerial). Sound is required: steel, horses, horns, screams, impacts. High graphics quality: photoreal mud and metal, dust, sparks, not a cartoon RTS. Art style: muddy historical epic, Kingdom Come / Ridley Scott battle. Go all out. Use a suitable name for the html file.

> **07 / 50**
>
> Create a single HTML file of a realistic 3D nuclear-blast simulation on an invented city. A brutal, massive explosion: blinding flash, a huge fireball, the shockwave shredding buildings, glass, fire, dust. Switch camera views (street, rooftop, aerial, from a car). Sound is required: a beat of silence on the flash, then the roar, sirens, glass, crowd panic. People running, cars crashing, the panic has to feel real. Art style: documentary, Threads / gray-orange, photoreal, not a video-game explosion sticker. Go all out. Use a suitable name for the html file.

> **08 / 50**
>
> Create a single HTML file of a super-realistic 3D black hole. It has to feel beautiful and majestic, like a cathedral in space, not a dark swirl in a void. A bright accretion disk (hot gold, orange, a blue edge), a sharp photon ring, gravitational lensing, the far side of the disk wrapping over the top, a dense star field stretching. You can orbit slowly and pull back until it feels enormous. Quiet rumble. Art style: Interstellar Gargantua, scientifically serious, cinematic, no cartoon vortex. Go all out. Use a suitable name for the html file.

> **09 / 50**
>
> Create a single HTML file of a 3D volcanic eruption on an invented town at the foot of the mountain. The mountain has to really explode: a brutal blast, a column of fire, rocks thrown, then lava and a pyroclastic flow swallowing streets, roofs catching, glass, ash night. Switch camera views (street, rooftop, aerial). Sound is required: the boom, rumble, screaming, collapsing wood, a rain of rocks. People running, the panic has to hit. Art style: photoreal documentary, Pompeii energy, gray ash and orange fire, not a cartoon volcano. Go all out. Use a suitable name for the html file.

> **10 / 50**
>
> Create a single HTML file of a 3D supercell tornado tearing through an invented town. A brutal wedge, debris flying, houses coming apart, cars lifted, rain sideways, a green-black sky. Switch camera views (street, porch, aerial). Sound is required: the roar, glass, wood ripping, sirens, panic. People running, the hit has to feel real. Art style: photoreal Twister / documentary, not a cartoon funnel. Go all out. Use a suitable name for the html file.

## 03 Tiny Universes

**Pixel art**

Honest pixels. A scene that keeps living.

> **11 / 50**
>
> Create a single HTML file of a living pixel-art sunset over the ocean with a lighthouse. The sun sinks, the beacon turns, waves loop, gulls, a small boat, maybe a keeper in the tower. Art style: 16-bit SNES, Secret of Mana sunset palette, 16 to 32 colors, sharp integer pixels, no blur. Go all out. Use a suitable name for the html file.

> **12 / 50**
>
> Create a single HTML file of a living pixel-art rainy city from a balcony. Rain loops, neon (invented signs), a plant, a cat, traffic as tiny lights below, a bit of the room behind you. Art style: VA-11 Hall-A / 90s anime pixel, magenta rain, night CRT, sharp pixels. Go all out. Use a suitable name for the html file.

> **13 / 50**
>
> Create a single HTML file of a living pixel-art medieval town waking up. Chimney smoke, a baker, chickens, a market opening, a castle on the hill, light going from blue to gold. Art style: SNES Zelda / Harvest Moon, earthy greens, that morning gold, chunky tiles. Go all out. Use a suitable name for the html file.

> **14 / 50**
>
> Create a single HTML file of a living pixel-art view from a spaceship window. Stars, a planet sliding by, a little phosphor HUD, a floating mug, someone walking past inside. Art style: FTL / 16-bit cockpit, phosphor-green HUD, deep space black. Go all out. Use a suitable name for the html file.

> **15 / 50**
>
> Create a single HTML file of a living pixel-art cherry blossom street in the wind. Petals piling up, bikes, a shop with a noren, evening lamps, maybe a tram. Art style: Chrono Trigger town, pink petals, warm evening, 16-bit, limited palette. Go all out. Use a suitable name for the html file.

## 04 Heard Things

**Music and song**

Original looping music in the page, 60 seconds, with a real player.

> **16 / 50**
>
> Create a single HTML file that plays a 60 second original looping song with a late-night car-radio scene as the player. Dashboard, a glowing radio, wet highway, headlights, rain on the windshield, the city as smears of light. Seamless loop, a real arrangement that changes over the minute (melody, drums, bass), not a 4-bar pad. Art style: Drive (2011) night highway, teal and magenta, wet asphalt, dark interior. Go all out. Use a suitable name for the html file.

> **17 / 50**
>
> Create a single HTML file that plays a 60 second original looping song inside a living pixel-art night city. Neon signs, a train, rain, windows lit, the whole scene moving with the beat. Seamless loop, a real arrangement that changes over the minute (melody, drums, bass), not a 4-bar pad. Art style: 16-bit SNES, VA-11 Hall-A / night-city pixel, magenta and teal, 16 to 32 colors, sharp integer pixels, no blur. Go all out. Use a suitable name for the html file.

> **18 / 50**
>
> Create a single HTML file that plays a 60 second original looping song on a spinning vinyl record. Seamless loop, a real arrangement that changes over the minute, not a 4-bar pad. Tonearm, dust, a sleeve with invented album art, the label turning. Art style: 1960s hi-fi magazine ad, teak wood, cream, a bit of orange, studio product shot. Make the object feel expensive. Go all out. Use a suitable name for the html file.

> **19 / 50**
>
> Create a single HTML file that plays a 60 second original looping song with a 1970s stereo receiver as the player. Walnut case, brushed aluminum, two VU meters whose needles actually follow the music, warm lamps. Seamless loop, a real arrangement that changes over the minute (melody, drums, bass), not a 4-bar pad. Art style: 1970s hi-fi catalog, walnut, cream, amber meters, studio product shot. Go all out. Use a suitable name for the html file.

> **20 / 50**
>
> Create a single HTML file that plays a 60 second original looping synthwave track (arpeggio, drums, a bassline) with a cassette player. Seamless loop, a real arrangement that changes over the minute, not a 4-bar pad. Reels turning, a tape counter, deck lights, invented deck brand. Art style: Outrun, magenta and cyan, chrome, dark, night-drive mood. Go all out. Use a suitable name for the html file.

## 05 The Long Take

**3D games and sims**

Playable 3D. Not a slideshow.

> **21 / 50**
>
> Create a single HTML file of a 3D Temple Run clone. Three lanes, run, jump, slide, turn, a chase behind you, temples and vines, coins, a high score, dying should sting. Art style: Uncharted jungle adventure, sun-bleached stone, dense green, game-cinematic 3D. Make it actually fun to play. Go all out. Use a suitable name for the html file.

> **22 / 50**
>
> Create a single HTML file of a 3D cannon launcher. Aim, set power, fire, the ball flies with real physics, smash wooden crates or a fort, the camera follows, try again. Art style: Pixar short, toy-like, bright, slightly clay, readable silhouettes. Go all out. Use a suitable name for the html file.

> **23 / 50**
>
> Create a single HTML file of a realistic 3D gun-shooting simulation on a firing range. Switch weapons and actually fire them so you can see what each one does: .50 cal (heavy recoil, long tracer, punch through steel), tank-piercing round (goes through a tank hull dummy), homing launcher (lock on, missile tracks), Kriss Vector (fast SMG, brass, muzzle), shotgun (pellet spread, close punch). Muzzle flash, recoil, impacts, smoke, sound. Art style: photoreal, documentary range, no cartoon guns. A sim of the effects, not a sticker of a gun. Go all out. Use a suitable name for the html file.

> **24 / 50**
>
> Create a single HTML file of 3D Flappy Bird. Tap to flap, pipes receding in space, a score, restart on hit. Invent a round cute bird, not the real one. Art style: cute clay, round, soft colors, real 3D not a 2D sprite stood up. Go all out. Use a suitable name for the html file.

> **25 / 50**
>
> Create a single HTML file of a 3D racing game like CSR Racing 2. Playable race, a glossy supercar, nitro, a shift, a night-city strip or drag strip, an opponent. Invent the cars, no real brand logos. Art style: CSR Racing 2, photoreal paint, neon city, wet asphalt, cinematic camera. Make it actually fun to play. Go all out. Use a suitable name for the html file.

## 06 The Boardroom

**Financial dashboards**

Dense and specific. Not three charts and a navy header.

> **26 / 50**
>
> Create a single HTML file of a Bloomberg-style trading terminal. Eight or more panels: live-feeling tickers, a watchlist, a chart, a news strip, maybe bonds, a small map, timestamps. Invent the data. Art style: real Bloomberg, black, amber and orange type, dense, no fintech gradients. Go all out. Use a suitable name for the html file.

> **27 / 50**
>
> Create a single HTML file of a Tesla-style investor dashboard. Deliveries vs plan, energy, a map, a stock-like chart, one huge number, a simple car silhouette. Invent the quarter. Art style: Tesla.com / car UI, white space, red accent, huge numbers, almost no chrome. Go all out. Use a suitable name for the html file.

> **28 / 50**
>
> Create a single HTML file of a live crypto trading dashboard. BTC plus a few alts, candles, an order book twitching, a heat map. Fake but dense. Art style: TradingView night mode, dark, green and red candles, neon ticks. It should feel like it is moving. Go all out. Use a suitable name for the html file.

> **29 / 50**
>
> Create a single HTML file of a luxury hotel revenue dashboard. Occupancy by room type, ADR, restaurants, a calendar, tonight's arrivals. Invent the property. Art style: Aman / quiet paper, sand and stone, small serif type, no neon. Go all out. Use a suitable name for the html file.

> **30 / 50**
>
> Create a single HTML file of a SpaceX-style launch control dashboard. T-minus countdown, fuel, telemetry, a trajectory map, four camera tiles that are graphic (not video files). Art style: mission control, huge screens, blue-gray, countdown grotesk, invented (no NASA or SpaceX logos). Go all out. Use a suitable name for the html file.

## 07 Time on Purpose

**Motion graphics**

A timed film that plays itself.

> **31 / 50**
>
> Create a single HTML file of a 25 second Apple-style product launch film. It plays itself. Invent a small object, light travels across it, type, a one-word name at the end. Art style: Apple keynote, black void, one object, slow light, tight sans. Replay. Go all out. Use a suitable name for the html file.

> **32 / 50**
>
> Create a single HTML file of a Netflix-style title sequence for a made-up show, about 20 seconds. It plays itself. Invent the title. Glimpses of a city or a room, then a last card with the name. Art style: True Detective season 1 titles, film grain, double exposure, slow type. Replay. Go all out. Use a suitable name for the html file.

> **33 / 50**
>
> Create a single HTML file of a 20 second film-studio opening ident. It plays itself. Invent the studio. Fragments or comic pages flip and assemble, then a mark that slams and a short sting. Art style: Marvel Studios intro, gold, panels, one invented mark. Do not copy a real logo. Replay. Go all out. Use a suitable name for the html file.

> **34 / 50**
>
> Create a single HTML file of a 20 second supercar commercial. It plays itself. Use real supercar photos from the web, do not invent or draw the car. Wet coast road, light on metal, a badge and a name at the end. Art style: Ridley Scott car film, wet asphalt, gold hour, slow. Replay. Go all out. Use a suitable name for the html file.

> **35 / 50**
>
> Create a single HTML file of a 20 second movie trailer title sequence. It plays itself. Invent the film title. Four or five cards, sparse frames, a rumble, then the title. Art style: A24 / Nolan, IMAX-scale type, loud cuts. Replay. Go all out. Use a suitable name for the html file.

## 08 Math as Paint

Fullscreen computed picture. Not a CSS gradient.

> **36 / 50**
>
> Create a single HTML file of a fullscreen aurora borealis shader. Slow curtains of light, a dark ridge of mountains, real-looking stars, the mouse can lean it. Art style: Iceland winter photograph, cold green and magenta, not a rainbow screensaver. Go all out. Use a suitable name for the html file.

> **37 / 50**
>
> Create a single HTML file of a fullscreen ocean wave shader. Long swell, foam at the lip, a horizon, maybe a low sun, mouse can tilt the light. Art style: photoreal midday Pacific, Gerstner-like water, not cartoon waves. You should want to stare at it. Go all out. Use a suitable name for the html file.

> **38 / 50**
>
> Create a single HTML file of a fullscreen galaxy shader you can fly through. A bright core, dust lanes, depth, you drift, drag or mouse to move, almost no UI. Art style: Hubble deep field, slow drift, real color, no clipart stars. Go all out. Use a suitable name for the html file.

> **39 / 50**
>
> Create a single HTML file of a fullscreen fire shader. Close crop, logs, heat shimmer, embers, it should feel hot. Art style: close-up campfire photograph, real logs, not a cartoon flame. Go all out. Use a suitable name for the html file.

> **40 / 50**
>
> Create a single HTML file of a fullscreen rain on glass shader. Drops that race, streaks, a neon street smear behind, a city that is only color. Art style: Chungking Express, neon smeared on wet night glass. Go all out. Use a suitable name for the html file.

Art style: dusty daylight construction site, documentary, gray and rust. Go all out. Use a suitable name for the html file.

> **42 / 50**
>
> Create a single HTML file of a Jenga game with real physics. A tall wood tower, pull or drag a block, the tower can fall, restart. Art style: studio product shot on an oak table, real wood grain, late light. Go all out. Use a suitable name for the html file.

> **43 / 50**
>
> Create a single HTML file of a bowling game with real physics. Aim, throw with power, 10 pins, a gutter, a simple frame score. Art style: 1980s American alley, rented-shoe lighting, beer-ad neon, polished wood. The throw should feel good. Go all out. Use a suitable name for the html file.

> **44 / 50**

> **48 / 50**

> **49 / 50**
>
> Create a single HTML file of a 3-Michelin-star restaurant website. Invent the name. A seasonal menu of 6 to 8 dishes, a chef's note, a reservation. Art style: Noma / Eleven Madison Park, natural light, one ingredient as hero, lots of white. No cheap stock-food look. Go all out. Use a suitable name for the html file.

> **50 / 50**
