## 01 Living Ink

**Animated SVGs**

A living vector scene. Not a logo spin.

> **01 / 50**
>
> I want an animated SVG mountain lake at dawn, one html file. Mist lifting, layered hills, pines, a still lake with a slow reflection, clouds drifting, a few birds as small marks. Scenery only, no people, no buildings. Ghibli background painting: soft greens and gold, big quiet shapes. A place you could sit in, not clipart hills. Go all out. Use a suitable name for the html file.

> **02 / 50**
>
> Make me an animated SVG hummingbird at a flower, one html file. It hovers then drinks, wings really beating, pollen, dew, the flower moving, a shadow on the paper. 19th century natural-history watercolor on cream, fine ink, wet color, a tiny invented latin label. Go all out. Use a suitable name for the html file.

> **03 / 50**
>
> Make me an animated SVG steam train crossing a mountain viaduct at night, one html file. Sparks, gold windows, smoke, a river and a tiny-light village below, the train actually goes across and loops. 1930s railway poster: deep navy, gold windows, a pale moon, big simple shapes. Go all out. Use a suitable name for the html file.

> **04 / 50**
>
> Make me an animated SVG peacock opening its train in a garden, one html file. The fan fills the page, eyespots catching light, a slow turn, a few small birds, plants at the feet. Mughal miniature: gold ground, jewel greens and blues, fine pattern, a thin border. The bird is the whole show, not a sticker with a triangle tail. Go all out. Use a suitable name for the html file.

> **05 / 50**
>
> Make me an animated SVG music box that opens, one html file. Lid lifts, a ballerina turns, tiny gears under glass, a few notes as gold specks, then it closes and starts again. Enamel and brass, cream, gold, dusty rose, like a Fabergé toy on a dark cloth. The mechanism is the show. Go all out. Use a suitable name for the html file.

## 02 Glass Worlds

**Three.js**

A big 3D simulation. Spectacle, not a quiet room.

> **06 / 50**
>
> Make me a 3D simulation of all-out war between two invented medieval kingdoms, one html file. A brutal valley battle: cavalry charges that hit, melee, arrow storms, siege engines slamming walls, fire, mud, banners in the smoke. The fight has to actually move and hurt, not idle in place. Let me switch cameras (ridge, in the melee, aerial). Sound is required: steel, horses, horns, screams, impacts. High graphics quality: photoreal mud and metal, dust, sparks, not a cartoon RTS. Muddy historical epic, Kingdom Come / Ridley Scott battle. Go all out. Use a suitable name for the html file.

> **07 / 50**
>
> Make me a realistic 3D nuclear-blast simulation on an invented city, one html file. A brutal, massive explosion: blinding flash, a huge fireball, the shockwave shredding buildings, glass, fire, dust. Let me switch cameras (street, rooftop, aerial, from a car). Sound is required: silence on the flash, then the roar, sirens, glass, crowd panic. People running, cars crashing, the panic has to feel real. Documentary, Threads / gray-orange, photoreal, not a video-game explosion sticker. Go all out. Use a suitable name for the html file.

> **08 / 50**
>
> Make me a super-realistic 3D black hole, one html file. It has to feel beautiful and majestic, like a cathedral in space, not a dark swirl in a void. Bright accretion disk (hot gold, orange, a blue edge), a sharp photon ring, lensing, the far side of the disk wrapping over the top, a dense star field stretching. I can orbit slowly and pull back until it feels enormous. Quiet rumble. Interstellar Gargantua, scientifically serious, cinematic, no cartoon vortex. Go all out. Use a suitable name for the html file.

> **09 / 50**
>
> Make me a 3D volcanic eruption on an invented town at the foot of the mountain, one html file. The mountain has to really explode: a brutal blast, a column of fire, rocks thrown, then lava and a pyroclastic flow swallowing streets, roofs catching, glass, ash night. Let me switch cameras (street, rooftop, aerial). Sound is required: the boom, rumble, screaming, collapsing wood, a rain of rocks. People running, the panic has to hit. Photoreal documentary, Pompeii energy, gray ash and orange fire, not a cartoon volcano. Go all out. Use a suitable name for the html file.

> **10 / 50**
>
> Make me a 3D supercell tornado tearing through an invented town, one html file. A brutal wedge, debris flying, houses coming apart, cars lifted, rain sideways, a green-black sky. Let me switch cameras (street, porch, aerial). Sound is required: the roar, glass, wood ripping, sirens, panic. People running, the hit has to feel real. Photoreal Twister / documentary, not a cartoon funnel. Go all out. Use a suitable name for the html file.
